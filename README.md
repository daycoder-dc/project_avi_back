## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run dev

# production mode
$ npm run build
$ npm run pro
```

## Resources
```toml
# Dominio del API
DNS=example.com.co

# Puerto local del servidor.
PORT=3000

# Enterno de ejecución (dev ó pro)
ENV=dev

# Cors configuración
ORIGIN=http://localhost

# Base de datos (Postgresql)
DB_HOST=localhost
DB_PORT=5432
DB_USER=my_user
DB_PWD=my_pass
DB_NAME=my_db

# Configuración SMTP
SMTP_HOST=smtp.example.com
SMTP_PORT=123
SMTP_SECURE=true
SMTP_USER=example@email.com
SMTP_PWD=my_pass
```
